# Level 7 Aim

Wallis product. The first level to try to visualise multiplying fractions together

## Level 7 Method

Wallis product: π/2 = (2/1)(2/3)(4/3)(4/5)(6/5)(6/7)...

## Level 7 Requirements

1. A bit like level 5. However, instead of adding things we need to multiply. So let's have the user enter a gun / turret that fires a multiplication laser. And you can fire it at the asteroid at the top of the fraction or at the bottom. So you go select the integer to multiply by and select the numerator or denominator and build up the multiplication series that way
2. Show the series at the top of the screen so you can see which numbers you have already done. Show the first n terms. Decide what is a good number for n which gets to a good answer but doesn't take the player to long to reach. Maybe between 5 and 10? 
3. You can multiply top or bottom in any order (correct me if I'm wrong) so it doesn't matter how the user builds up the asteroid. But visually it will probably look better if they go bit by bit otherwise the asteroid won't fit on the screen

# Level 5 Aim

Add several terms in the Basel Problem infinite series to estimate pi

## Level 5 Method

Basel Problem

This is an infinite sum but all terms are positive. So we can try a different approach / style to the Leibniz series.

## Level 5 Requirements
1. Build a large asteroid bit by bit - each bit is a term in the sequence. Ideally they could be scaled correctly but this may be asking a lot as the terms grow so much.
2. To gamify it the asteroid could be going in an orbit and the user has to point an 'asteroid gun' up and down and press fire at the right time so it hits the asteroid which then grows. If you miss, you just try again with the same term
3. The first asteroid we fire can be the first term and it can be captured by the orbit. 
4. Then the user has to go and select the next terms from a stockpile below. This way you can see the relative sizes. 
5. Let's have a maximum number of terms - perhaps 6. It will converge quickly and it will be very hard to visualise the size of the rock we are adding beyond this
6. At any point we can choose the different ammo (a 'duplicator') which multiplies the rock by 6. Maybe you see it duplicate into 6 and then recombine into 1 larger rock
7. We then also need to square root it. This can be another different ammo (different colour laser?). This laser should split the large rock into something much smaller now. The debris can fly off screen leaving a single rock. Pi can go pick this up and add it to a weighing scale at the top which can then reveal the number we have calculated
8. The sequence doesn't converge that quickly but this setup will be very hard to visualise with lots of terms. So perhaps 10 is the max for this

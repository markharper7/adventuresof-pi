# Theme

## General 
In general, the game should have one theme and the feeling in each level should be consistent.

In the future, it may be a fun option to be able to swap between themes. Therefore, keep this in mind when designing the code base.

Across all themes, we likely want a square based grid for the user to walk around on. 

## Boundary
There should also be some boundary which matches the theme so that the user can't just walk anywhere.

It will be more fun and interesting if the boundary is shaped and themed in some way rather than just a square / rectangular grid which the user can't leave but has no obvious edge to it. 

## Theme options
1. Space
    - Default theme. Use this unless we start a conversation around themes and are actively looking to change the theme
    - Circles are naturally orbits
    - Meteors randomly passing through areas or hitting objects can be used in some contexts such as random sampling methods
    - Fuel for stars could be used to make them grow and shrink for infinite series methods
    - The boundary 
2. Greek temples + forest
    - This was done in an early iteration (not in this repository) and worked quite well. 
    - The circles can be drawn on temple floors - with square tiles
    - A campfire with wood as fuel and water as negative fuel was used well for infinite series

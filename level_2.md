# Level 2 Aim

A circle is drawn on the floor. The user can then try to draw this circle by stepping the pi character up, down, left and right and estimating pi from a count of their steps and counting the squares for the diameter

There should be multiple stages in the level - a circle in each stage, each of varying size. This will show different values of pi.

## Level 2 Method
Leibniz series

## Level 2 Requirements
1. A fun way to sum fractions. Other levels will do this so it needs to be reusable
2. A way of handling adding a negative fraction
3. The level must be interactive. Perhaps the user can pick up a certain number of blocks to represent the fraction and place them in a pile or pit in the middle
4. The user should see the current value of pi the whole time so they can see it iterating towards a number. 
5. Each 'part' of the level can be a single fraction.  Blocks can disappear between each part for example
6. To keep the level engaging, the user should have to click something to pick up a block and then walk it to the pit
7. Ideally the size of the blocks could represent the fraction. Could we draw a large shape on the floor and show how the blocks together make that shape. Could the shape be consistent across all fractions or is that too difficult?
8. The user should be able to pick up any of these blocks i.e. they choose. They should pick up the block they are most on top of  
9. The running total is shown but we also want to show the current value for pi
10. The blocks could be obviously water and fire and the pitt is a fire pit. So visually a postive fraction (wood) increases the fire while a negative one (water) lessons the fire.
11. Could the style of this instead be a forest? Wood from trees, water from a stream or
  waterfall or something and a fire in the middle.

## Debug Requirements
1. Ability to jump to a 'part' within this level
